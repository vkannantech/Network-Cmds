## 1. Experiment Number & Title
- **Experiment No**: 10

## 2. Aim
To design, configure, and simulate an integrated hybrid **SOHO network** using **Cisco Packet Tracer** with wired/wireless LANs, cable broadband cloud, and a centralized server providing DHCP and DNS services.

---

## 3. How to Run

Thus, the network topology incorporating wired, wireless, cable broadband, and server services was successfully designed, configured, and simulated using Cisco Packet Tracer.
